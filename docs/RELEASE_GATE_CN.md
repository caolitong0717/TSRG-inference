# 发布范围与科研档案分离

**TSRG-inference：用户使用版。** 只保留独立推理、安装指导、有限许可、单元测试和最小 ZIP 的打包程序。**TSRG：科研投稿版。** 继续保留 R18/R19/R20 V3 原始 Notebook、运行记录、独立测试预测、冻结协议与 SHA256 审计材料。两套分别审核，使用版不会自动复制科研档案。

已经完成：双 Tesla T4 FP16 新照片 Notebook 两类路由检查；独立命令行寒山寺样例退出码 0 且与原 Notebook 一致；精简 ZIP 白名单和 SHA256 校验。

正式公开前待确认：研究成员署名和同意、R19 适配器分发许可、Puffin 的 S-Lab License 1.0 与其他第三方权利、仓库历史中的个人信息及敏感材料。没有验证单 GPU、普通笔记本本地大型模型推理、通用自动景点分类或网页图片生成功能。现阶段仓库保持 Private。

## 已确定的计划与待通过的审核

项目所有者选择：**代码和 R19 Epoch-3 LoRA 最终都公开提供下载，但必须先完成授权审核**。代码仓库计划设为 Public；R19 适配器计划通过独立发布附件提供 `adapter_model.safetensors`、`adapter_config.json` 及 SHA256 清单。Puffin 基础权重保持官方获取方式；原科研档案仓库 TSRG 继续 Private。

当前仍需确认合作者署名与公开同意、训练材料和上游许可对 LoRA 再分发的适用范围、将要上传的实际二进制校验与敏感信息检查。详情见 [公开授权审核记录](PUBLIC_RELEASE_AUDIT_CN.md) 与 [R19 模型卡](R19_MODEL_CARD_CN.md)。上述审核完成前不切换 Public、不公开上传权重。

官方 Puffin 源码使用 S-Lab License 1.0（非商业使用等条件），本仓库没有包含上游源码或原始基础权重；对模型适配器的公开分发，仍需按照权利归属和上游适用条款单独审核。本仓库任何 MIT 范围说明都不能覆盖第三方模型和文件。确认之前不得把整个研究档案仓库设为 Public 或自动上传私有权重。
